Arquitetura Multi-Tenant & Hub Central
100% Isolado & Ativo

O Pulse ERP funciona como o cérebro central unificado. O administrador do SaaS registra a aplicação integradora homologada nos canais, enquanto cada lojista (tenant) conecta sua loja isolada sem ter contato com chaves mestras ou infraestrutura.

Isolamento Rígido

Isolamento pelo usuario_id (UUID). Cada loja só acessa seus próprios anúncios, pedidos, estoques e taxas.

Webhook Fast-ACK

Resposta imediata em menos de 100ms com HTTP 200 para evitar reenvio de notificações e penalidades dos canais.

Blindagem Fiscal

NF-e emitida no CNPJ do lojista e repasses financeiros caindo direto na conta jurídica de cada cliente.

Integração com o Mercado Livre (MELI)
Conector Completo
Passo a Passo para o SaaS Admin (1 única vez)
  1. Acesse o Mercado Libre Developers com a conta jurídica da sua plataforma.
  2. Crie uma aplicação integradora do tipo "Integrador / ERP".
  3. Habilite os escopos: read, write, offline_access.
  4. Preencha a Redirect URI e a Webhook URL abaixo.
Experiência do Lojista (Tenant)
  1. O lojista acessa o menu Marketplaces > Mercado Livre no Pulse.
  2. Clica no botão "Conectar Loja do Mercado Livre".
  3. Faz login oficial no Mercado Livre e concede acesso em 1 clique.
  4. O Pulse armazena o vínculo seguro e inicia a sincronização bidirecional.

URLs de Configuração no Portal de Desenvolvedor Meli

Redirect URI (Callback OAuth) 
https://seusite.com.br/marketplace/config/oauth-callback?marketplace=MERCADO_LIVRE
Notifications Callback URL (Webhook Ingestion) 
https://seusite.com.br/marketplace/webhook/receive?marketplace=mercado-livre
Tópicos Obrigatórios de Webhook: Certifique-se de marcar orders_v2 (pedidos novos/atualizados), items (anúncios) e shipments (etiquetas e envios do Mercado Envios).

Recursos Já Codificados no Conector Meli

  • Sincronização de Estoque com Variações: Atualiza no anúncio pai ou variações específicas.
  • Precificação Inteligente: Aplica o percentual de markup configurado pelo lojista.
  • Transmissão Fiscal (NF-e): Envio da chave de 44 dígitos e XML Danfe via /orders/{id}/fiscal_documents.
  • Etiquetas Mercado Envios: Emissão do PDF da etiqueta via /shipment_labels.
Integração com a Shopee (Open Platform v2)
Conector Completo
Papel do SaaS Admin
  1. Homologar a plataforma no Shopee Open Platform.
  2. Obter o Partner ID e a Partner Key para a região Brasil.
  3. Configurar a URL de Push Notification (Webhook) oficial.
Papel do Lojista
  1. Possuir conta ativa no Shopee Seller Centre com CNPJ cadastrado.
  2. No Pulse ERP, clicar em "Conectar Shopee".
  3. Concluir o login da loja e autorizar o aplicativo do Pulse.

Assinatura Criptográfica HMAC-SHA256

A API v2 da Shopee exige que todas as chamadas e webhooks contenham a assinatura criptográfica calculada com timestamp e chaves oficiais:

Shopee Webhook Receiver URL 
https://seusite.com.br/marketplace/webhook/receive?marketplace=shopee
Criptografia Implementada no Pulse: O método ShopeeService::generateSignature() calcula automaticamente o hash HMAC-SHA256 conforme o padrão oficial da Shopee (partnerId + path + timestamp + accessToken + shopId), renovando tokens e validando push notifications.
Integração com o Magazine Luiza (Magalu Marketplace)
Conector Completo
Visão da Plataforma SaaS

A integração do Magazine Luiza é suportada pela API da IntegraCommerce / LuizaLabs. A plataforma permite tanto o modelo de integradora homologada quanto a autenticação por API Token de cada seller.

Como o Lojista Conecta
  1. Acessar o portal Magalu Seller.
  2. Ir em Configurações da Loja > Integrações / API.
  3. Gerar e copiar o Token de API (Bearer Token).
  4. Colar no campo correspondente no painel do Pulse ERP.

Integração com a Temu (Local-to-Local Brasil)
Conector L2L Pronto
O que é o programa Temu L2L (Local-to-Local Brasil)?
É a modalidade onde vendedores brasileiros com CNPJ e estoque local no Brasil anunciam e despacham seus produtos para clientes nacionais via correios ou transportadoras locais com entrega expressa.
Papel do SaaS Admin
  1. Cadastro de parceiro integrador no Temu Open Platform.
  2. Obtenção do App Key e App Secret da região BR.
Papel do Lojista
  1. Aprovação prévia no portal de sellers locais da Temu Brasil.
  2. Obter a chave de vendedor local (Seller Token).
  3. Informar no Pulse ERP e ativar a sincronização.

Integração com o iFood (Merchant API v2)
Fase 2 / Expansão

Dedicada a comércios de conveniência, adegas, farmácias, mercados e restaurantes. A integração permite receber novos pedidos instantaneamente no módulo de vendas do Pulse, imprimir comandas e controlar status de entrega.

Configurações do SaaS Admin
  1. Cadastro no iFood Developer Portal.
  2. Obtenção de Client ID e Client Secret.
  3. Cadastrar a URL de Webhook no portal iFood Developer.
Configuração do Lojista
  1. Possuir loja cadastrada no Portal do Parceiro iFood.
  2. Informar o seu Merchant ID no Pulse ERP.
  3. Autorizar o aplicativo e definir a impressora padrão de pedidos.

Mercado Pago (Gateway & Maquininha Point no PDV)
100% Homologado
Modelo White-Label & Repasse Direto: Cada lojista recebe os pagamentos de cartão de crédito, débito e PIX direto na sua conta Mercado Pago. O dinheiro nunca passa pela conta do Pulse ERP, garantindo total transparência e segurança bancária.
O que o SaaS Admin Configura
  1. Acessar o Painel de Desenvolvedores Mercado Pago.
  2. Criar uma aplicação do tipo "Marketplace / Pagamentos".
  3. Colocar as credenciais no arquivo .env da VPS: 
    MP_APP_ID=seu_client_id_aqui
MP_CLIENT_SECRET=seu_client_secret_aqui
Integração com Maquininha no PDV
  1. O lojista adquire ou utiliza sua maquininha física (Point Smart, Pro, Air).
  2. No Pulse ERP, clica em "Conectar com Mercado Pago".
  3. Ao finalizar uma venda no PDV, seleciona o terminal Point e o valor é enviado instantaneamente para a maquininha física.
