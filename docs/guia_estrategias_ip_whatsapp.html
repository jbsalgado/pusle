VPS EUA → Disparos Brasil sem Proxies Pagos

Produção Ativa
Visão Geral do Cenário

Como evitar bloqueios por IP com VPS nos EUA disparando para números no Brasil

A Meta/WhatsApp analisa o ASN do IP e a geolocalização das sessões Web (Baileys/Evolution). Quando um número com DDD brasileiro conecta repetidamente a partir de um IP de Datacenter nos Estados Unidos, os algoritmos heurísticos elevam o risco de bloqueio.

Abaixo estão os 3 métodos definitivos para resolver essa limitação sem gastar mensalidades com serviços de proxy residencial.

Opção 1 • Recomendada ⭐

Meta Cloud API (Oficial)

Isenção total de IP do servidor. Conexão oficial direta com a Meta Graph API.
Opção 2 • 100% Grátis 🛡️

Túnel Tailscale Exit Node

Escoa o tráfego da VPS nos EUA através da sua conexão residencial no Brasil via WireGuard.
Opção 3 • Gateway SP ⚡

Micro-VM em São Paulo

Motor Evolution instalado em uma VM Always Free da Oracle Cloud na região de São Paulo.
1

Opção 1: API Oficial da Meta (WhatsApp Cloud API)

A solução mais estável, corporativa e sem restrições de localização de servidor.

💡 Por que o IP não importa aqui?
Na API Oficial da Meta, as mensagens saem dos servidores mundiais do Facebook/Meta diretamente para o celular do cliente. A Meta não analisa o IP do seu servidor PHP nos EUA, porque a autenticação é feita com Token de Sistema Permanente e WABA ID vinculados à sua conta Business Manager.

Passo a Passo de Configuração:

1

Criar App no Meta for Developers

Acesse developers.facebook.com → Meus Apps → Criar App → Tipo: Empresa (Business) → Adicionar o produto WhatsApp.

2

Copiar as Credenciais do Painel

Na aba WhatsApp → Primeiros Passos, copie os seguintes dados:

  • Phone Number ID: Identificador do número de telefone (ex: 109283746592817)
  • WABA ID: WhatsApp Business Account ID (ex: 104829384918234)
3

Gerar Token Permanente de Usuário do Sistema

Acesse o Meta Business Suite → Configurações da Empresa → Usuários do Sistema:

Crie um usuário com função Administrador e gere um token com as seguintes permissões:

whatsapp_business_messaging whatsapp_business_management
4

Salvar no Painel do Pulse

Acesse o ERP em https://catalogos.oncode.app.br/evolution/config:

Clique na aba WhatsApp Oficial (Meta Cloud API), cole o WABA ID, Phone Number ID, Access Token e clique em Salvar Credenciais da Meta.

5

Configurar o Webhook de Retorno na Meta

No painel do Meta for Developers, configure o Webhook com os dados:

Callback URL: https://catalogos.oncode.app.br/evolution/meta-webhook/index

Verify Token: pulse_meta_webhook_token_2026

Campos Assinados: messages, message_template_status_update

Opção 2: Túnel Privado Tailscale / WireGuard (100% Gratuito)

Roteia a conexão do WhatsApp para sair com o IP residencial legítimo da sua internet no Brasil.

🛡️ Como Funciona?
O Tailscale cria uma rede mesh P2P segura criptografada (WireGuard). Você define um computador ligado no Brasil (seu PC, notebook ou Raspberry Pi) como Exit Node. A VPS nos EUA roteia o tráfego da Evolution através desse nó brasileiro. O WhatsApp enxerga a conexão saindo diretamente da sua operadora (Vivo, Claro, Oi, etc.), com reputação residencial perfeita.

Passo a Passo de Instalação:

1

Criar Conta Gratuita no Tailscale

Acesse tailscale.com e crie uma conta gratuita (suporta até 100 dispositivos).

2

Configurar a Máquina no Brasil como Exit Node

No computador que fica no Brasil (Linux ou Raspberry Pi):

# 1. Habilitar encaminhamento de pacotes IP no Linux

echo 'net.ipv4.ip_forward = 1' | sudo tee -a /etc/sysctl.d/99-tailscale.conf

sudo sysctl -p /etc/sysctl.d/99-tailscale.conf

# 2. Iniciar o Tailscale anunciando como Exit Node

sudo tailscale up --advertise-exit-node

(No Windows/Mac, basta abrir o app Tailscale → clicar com botão direito → Marcar "Run as exit node").

3

Aprovar o Exit Node no Painel Web

Acesse o painel do Tailscale (login.tailscale.com/admin/machines) → localize a máquina do Brasil → clique nos 3 pontinhos → Edit route settings → Marque Use as exit node.

4

Instalar e Conectar na VPS dos EUA

Acesse o terminal da sua VPS nos EUA (2.25.182.204) e execute:

# Instala o Tailscale na VPS

curl -fsSL https://tailscale.com/install.sh | sh

# Conecta a VPS usando o nó do Brasil como saída

sudo tailscale up --exit-node=<NOME_OU_IP_DA_MAQUINA_BRASIL> --exit-node-allow-lan-access=true

# Testa se o IP público de saída mudou para o Brasil:

curl ifconfig.me

Opção 3: Micro-Gateway Evolution em São Paulo (Oracle Cloud Always Free)

Separação de papéis: O ERP continua na VPS dos EUA e apenas o motor Evolution roda no Brasil.

⚡ Arquitetura Desacoplada:
A Oracle Cloud disponibiliza até 4 instâncias gratuitas vitalícias na região Brazil East (São Paulo / Vinhedo). Você sobe uma micro-VM gratuita em SP rodando exclusivamente o motor Go do WhatsApp. O ERP Pulse nos EUA apenas faz requisições REST internas para essa VM brasileira.

Passo a Passo de Implantação:

1

Criar VM Gratuita na Oracle Cloud São Paulo

Cadastre-se em cloud.oracle.com → Escolha como Home Region: Brazil East (São Paulo) → Crie uma instância Always Free (Ubuntu 22.04 / 24.04).

2

Instalar o Motor Evolution Go na VM de SP

No terminal da VM brasileira, instale o binário Go ou Docker:

# Baixa e executa a Evolution API Go

git clone https://github.com/EvolutionAPI/evolution-go.git

cd evolution-go

cp env.example .env

# Configure a AUTHENTICATION_API_KEY no .env

docker compose up -d

3

Apontar o ERP Pulse para o Gateway Brasileiro

No arquivo config/params.php do Pulse na VPS dos EUA, altere a URL base da Evolution:

'evolution' => [
    'base_url'       => 'http://IP_DA_VM_SAO_PAULO:8080',
    'global_api_key' => 'SUA_CHAVE_GLOBAL',
],
