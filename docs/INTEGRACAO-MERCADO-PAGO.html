Manual Completo de Integração Mercado Pago

Guia passo a passo de cadastro no portal Mercado Pago Developers, configuração da taxa de Split de comissão, integração com o Catálogo Online PWA e relatório técnico do ecossistema Pulse.

1. Passo a Passo: Cadastro no Mercado Pago (Plataforma Master)
Configuração Inicial
1. Criar Conta Dev no Mercado Pago
Acesse o portal oficial do Mercado Pago Developers: mercadopago.com.br/developers e faça login com a conta principal (dono da plataforma Pulse).
2. Criar Nova Aplicação (App)
Vá em "Suas aplicações" → "Criar aplicação":
- Nome da aplicação: Pulse Plataforma SaaS
- Tipo de solução: Pagamentos Online / Marketplace
- Modelo de integração: OAuth (Marketplace / Subcontas)
3. Copiar Credenciais Globais para o .env
No painel da aplicação, copie a Client ID e o Client Secret e adicione no arquivo .env da VPS: 
MP_APP_ID="SEU_CLIENT_ID_MERCADOPAGO"
MP_CLIENT_SECRET="SEU_CLIENT_SECRET_MERCADOPAGO"
MP_REDIRECT_URI="https://top-construcoes.catalogo.cloud/index.php/api/mercado-pago/oauth-callback"
4. Configurar URLs de Redirecionamento e Webhook
No painel da aplicação do Mercado Pago, cadastre:
- Redirect URI (OAuth): https://seu-dominio.com/index.php/api/mercado-pago/oauth-callback
- URL de Webhook (Notificações): https://seu-dominio.com/index.php/api/mercado-pago/webhook
- Eventos Ativados: Pagamentos (payment) e Intenções de Pagamento Point (payment_intent)
2. Como Registrar e Ajustar a Taxa do Split (Comissão)
Split Automático
Funcionamento do Split: Em cada venda (seja por PIX Transparente, Maquineta Point ou Checkout Web), o Mercado Pago retém automaticamente a porcentagem definida e transfere a comissão direta para a conta do proprietário da plataforma Pulse, enviando o líquido restante para o lojista vendedor.
Taxa Padrão Global da Plataforma
Definida no arquivo config/params.php:
'pulse_platform_fee_percent' => 0.005
(0.005 = 0.5%, 0.01 = 1.0%, 0.02 = 2.0%).
Taxa Individual por Lojista (Banco SQL)
Para personalizar a comissão de uma loja específica, atualize a coluna taxa_comissao na tabela prest_usuarios:
UPDATE prest_usuarios SET taxa_comissao = 0.01 WHERE id = 'UUID_DA_LOJA';
3. Integração do Catálogo Online PWA (Vendas Online)
Já Integrado & Operacional

O módulo do Catálogo Online PWA (web/catalogo) já possui integração nativa e unificada com o backend do Mercado Pago.

Etapa no Catálogo Arquivo Responsável Ação do Sistema
1. Escolha da Forma web/catalogo/js/gateway-pagamento.js O cliente final seleciona a opção de pagamento via Mercado Pago / PIX.
2. Emissão PIX Split API_ENDPOINTS.MERCADOPAGO_CRIAR_PIX_SPLIT O backend gera o QR Code em Base64 e o código Copia-e-Cola já com o Split retido.
3. Modal & Sandbox Test mostrarModalPix() Apresenta o QR Code na tela com o botão oficial 🧪 Testar Confirmação (Sandbox) para validações de teste.
4. Polling & Confirmação iniciarPollingStatusVenda() Consulta /api/pedido/status?venda_id=XXX a cada 5 segundos até a aprovação.
5. Baixa & WhatsApp MercadoPagoController.php Ao aprovar, marca a venda como QUITADA, registra o Caixa, baixa estoque e dispara recibo no WhatsApp do cliente.
4. Resumo da Arquitetura Técnica
100% Concluído
Renovação de Token (refresh_token)
Função renovarTokenOauth() integrada ao obterTokenVendedor() renovando tokens automaticamente caso faltem 7 dias para expirar.
Validação HMAC x-signature
Função validarAssinaturaWebhook() checando a assinatura HMAC SHA-256 no actionWebhook.
Conexão OAuth na Interface
Botão "Conectar com Mercado Pago" adicionado ao modal de maquinetas no Venda Direta acionando o link de autorização.
Tratamento de Recusa na Point
Webhook interpreta CANCELED / FAILED e notifica o frontend para fechar o modal e avisar o usuário imediatamente.
